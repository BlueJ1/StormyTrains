The completed notebooks show the workflow and summary results. Detailed monthly tables, charts, source diagnostics and execution manifests are retained locally and are regenerated by running the notebooks with the original archives. They are not included in this compact quality folder. Review decisions are input files: preserve their contents and exact relative paths. The temperature context snapshot is generated before its saved hash is checked; no additional stored quality file is required as an input.

Running a notebook will create additional local quality outputs; those generated outputs do not need to be uploaded. Raw DWD archive versions, matching station mappings, Python dependencies and the processing code remain required to rerun the workflow. The saved decisions document project source choices, not independent confirmation that each observation is accurate.
